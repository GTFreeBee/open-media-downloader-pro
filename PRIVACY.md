# Privacy

Open Media Downloader Pro does not include project-owned analytics, advertising or telemetry.

The application stores settings, queue recovery data and diagnostic logs locally. When inspecting or downloading a URL, it connects to that site and any media hosts selected by yt-dlp. It also contacts GitHub and the pinned FFmpeg release host to check and retrieve managed tool updates.

Cookie files are selected by the user and passed locally to yt-dlp. They are not uploaded to a project-owned service. Diagnostic reports can contain URLs, output paths and site error text; review them before sharing.

Removing the application does not automatically delete downloaded media. The uninstaller preserves local application data by default to avoid accidental loss.

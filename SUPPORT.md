# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible defects.

Before opening an issue:

1. Install the latest release.
2. Retry outside a synchronized destination folder.
3. Confirm the link works in a normal browser.
4. Copy the application's failure report from Diagnostics.
5. Remove private URLs, filenames and account information before posting.

Include the application version, operating system, installer type, expected result and exact steps. Project maintainers cannot help bypass access controls, digital restrictions, subscriptions or site permissions.
